# COS 106 Student Portfolio and Academic Management Website

**Student:** Chidubem Kelvin Ikechukwu  
**University:** Miva Open University  
**Course:** COS 106 – Introduction to Web Technologies

## Features
- Five linked HTML pages: Home, About, Projects, Academic Planner, Contact
- Semantic HTML, tables, lists, images, links, forms, audio
- External responsive CSS, Grid, Flexbox, transitions and mobile navigation
- JavaScript task creation/completion/deletion with localStorage
- Contact form JavaScript validation (no backend; form does not transmit messages)

## Add your real portrait (important)
Rename your photograph to **profile.jpg** and place it inside the **assets** folder. The website includes a styled CK fallback until the photo is added.

## Publish to GitHub Pages
Upload the contents of this folder (not the parent folder) to the repository root. Under Settings → Pages, deploy from main branch / (root).

## Notes
The three projects are illustrative learning examples; the network project is not a deployed network. The short audio is a generated musical demo tone, not a spoken explanation. Replace with your own narration if desired.
